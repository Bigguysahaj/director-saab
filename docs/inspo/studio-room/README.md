# Studio room inspo

`ai4anim-webgpu-debug-ui.png` — debug viewer screenshot from
[sweriko/ai4anim-webgpu](https://github.com/sweriko/ai4anim-webgpu), saved
2026-09-06 as inspiration for a future `/stage` studio-room pass.

What it's showing that's worth stealing:
- Two softbox-on-stand key/fill lights framing the subject on a plain dark
  floor — clean neutral studio look, closer to a real photo studio than the
  current flat wall + floor backdrop.
- A collapsible runtime debug panel (style/speed/timescale/sync/blend) and a
  foot-contact panel (L/R Ankle, L/R Ball) for a physics-driven mocap
  character — relevant if the mannequin ever gets real IK / live mocap
  driving (see TODO.md's Mannequin future plan).
- Perf HUD (FPS/CPU/GPU/tris/calls) tucked in a corner, unobtrusive.

Not a spec to copy exactly — just a reference for lighting rig look and
debug-panel layout density.
